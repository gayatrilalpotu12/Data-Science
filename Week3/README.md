# Sales Data Analysis Project

## Project Overview
This project performs sales data analysis using Python and Pandas. It analyzes sales records, cleans the dataset, calculates sales metrics, and generates a final sales report.

## Technologies Used
- Python 3.13
- Pandas
- CSV Dataset
- VS Code

## Project Features
- Load sales dataset
- Display first five records
- Check dataset information
- Identify missing values
- Remove duplicate records
- Clean and process data
- Calculate total revenue
- Find best-selling products
- Analyze region-wise sales
- Perform monthly sales analysis
- Generate final sales report

## Project Files
- Sales analysis.py – Python source code
- sales_data.csv – Original dataset
- cleaned_sales_data.csv – Cleaned dataset
- analysis_report.md – Final analysis report
- Screenshots – Project output screenshots

## How to Run

1. Install Python.
2. Install Pandas using:

```bash
py -m pip install pandas
```

3. Run the project:

```bash
py "Sales analysis.py"
```

## Output
The project generates:
- analysis_report.md
- cleaned_sales_data.csv

## Conclusion
This project demonstrates practical data analysis using Python Pandas. It helps understand sales performance, product revenue, customer transactions, and regional sales.
